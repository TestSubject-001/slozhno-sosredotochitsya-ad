# Сложно сосредоточиться

Адаптивный лендинг о том, почему нам сложно концентрироваться, и о способах вернуть внимание. Свёрстан по макету Яндекс Практикума.

## Что реализовано

- mobile first и «резиновая» вёрстка на CSS Grid;
- тёмная, светлая и автоматическая темы с переключением по кнопкам и через `prefers-color-scheme`;
- сохранение выбранной темы в `localStorage` (скрипт из стартового шаблона);
- декоративные уголки и надпись REC через псевдоэлементы;
- адаптивная галерея с «ленивой» загрузкой изображений;
- локальные шрифты, переменные CSS, состояния ссылок и кнопок.

## Технологии

HTML5, CSS3 (Grid, custom properties, `clamp()`, media queries), JavaScript из стартового шаблона.

## Как запустить

Откройте `index.html` в браузере или запустите локальный сервер в корне проекта:

```bash
npx http-server .
```
